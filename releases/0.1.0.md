# 0.1.0 릴리스

첫 배포는 DDD로 정리한 업무 규칙을 OpenSpec 명세, 구현 작업, 검증 기록으로 연결할 수 있는 프로젝트 시작 구조를 제공합니다.

- 시작 문서와 공통 안내, DDD 양식, 검토 체크리스트 및 스킬 원본은 [배포 목록](distribution-map.json)에 명시합니다.
- AI 도구 연결은 Codex, Claude Code, Cursor용 진입점 또는 스킬 복사본을 생성하고 연결 원본 및 해시를 기록합니다. 지원 상태는 [도구 연결 안내](../integrations/README.md)에서 확인합니다.
- 문서 검사는 시작 문서와 링크, 선택한 변경의 명세 및 작업 추적을 확인합니다.
- 내보낸 폴더와 ZIP의 관리 도구는 SHA-256으로 기준을 비교하고, 수동 반영과 연결 갱신 후 새 관리 경로를 경로별로 승인하고 버전을 기록할 수 있습니다. 배포 후 `.foundation/updating.md`에서 적용과 되돌리기 절차를 확인합니다. [업데이트 안내 원본](../distribution/managed/updating.md)

## 실행과 호환성

관리 도구의 실행 기준은 Node.js 22.20.0 이상이며 OpenSpec 초기 호환성 대상은 2.1.0입니다. 업데이트 및 기준 기록 도구는 Windows x64의 Node.js 24.14.0에서 ZIP을 풀어 확인했습니다. AI 세션에서의 스킬 사용, 제품 테스트 및 배포는 프로젝트에서 별도로 검증합니다.

기존 프로젝트 구성을 반영할 때는 ZIP의 시작 양식에서 필요한 내용을 선별합니다. 프로젝트 문서 및 OpenSpec 계약은 프로젝트의 관리 절차에 따라 편집합니다.
