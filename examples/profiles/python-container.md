# Python · 컨테이너 설정 예시

## 기술 선택

Python과 FastAPI를 사용하며 PostgreSQL에 저장한다. OCI 이미지를 컨테이너 호스트에서 Docker Compose로 실행한다.

## 코드 규칙

도메인 함수가 웹 프레임워크에 의존하지 않게 한다. 요청 검증과 오류 매핑은 웹 계층이 맡는다. 서비스 동작은 pytest로, DB 제약은 별도 통합 테스트로 확인한다.

## 검토 방식

개발자가 변경을 자체 검토하고 변경 폴더의 검증 기록에 AC별 결과를 남긴다.

## 실행·테스트·배포 명령

| 용도 | 예시 명령 | 실행 위치·선행 조건 |
| --- | --- | --- |
| 실행 | `uvicorn app.main:app` | 프로젝트 루트, 가상 환경과 개발 DB 준비 |
| 테스트 | `python -m pytest` | 루트, 테스트 의존성과 전용 DB 준비 |
| 배포 | `docker compose up -d` | 컨테이너 호스트, 검증한 이미지 태그·환경 설정과 배포 권한 필요 |

## 미정 사항

이미지 보존 기간과 이전 태그 복구 절차를 첫 배포 전에 확인한다. 위 명령은 가상 프로필의 기입 예이며 실행 결과는 없다.
