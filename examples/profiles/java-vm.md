# Java · 가상 머신 설정 예시

## 기술 선택

Java와 Spring Boot를 사용하며 PostgreSQL에 저장한다. 실행 환경은 Linux 가상 머신과 systemd다.

## 코드 규칙

업무 규칙은 도메인 모듈에 둔다. HTTP 계층에서 입력을 검증하고 도메인 오류를 응답으로 변환한다. 상태 전이는 단위 테스트로, 트랜잭션은 저장소 통합 테스트로 확인한다.

## 검토 방식

개발자가 명세와 테스트를 대조하고 PR에 AC별 결과를 기록한다.

## 실행·테스트·배포 명령

| 용도 | 예시 명령 | 실행 위치·선행 조건 |
| --- | --- | --- |
| 실행 | `./gradlew bootRun` | 프로젝트 루트, JDK와 로컬 DB 준비 |
| 테스트 | `./gradlew test` | 루트, 프로젝트 Gradle 래퍼 필요 |
| 배포 | `systemctl restart reservation` | 대상 VM, 검증한 JAR 설치와 서비스 설정 후 권한 있는 운영자가 실행 |

## 미정 사항

장애 시 이전 JAR로 복구하는 절차는 첫 배포 전에 확인한다. 위 명령은 가상 프로필의 기입 예이며 실행 결과는 없다.
