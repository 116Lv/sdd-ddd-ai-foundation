## 1. 준비

- [ ] 1.1 요청 키 유효 기간과 만료 후 처리 방식을 결정해 프로젝트 루트 `docs/domain/cancellation-policy.md`의 R-03에 먼저 기록한다. 그 규칙에 맞춰 AC-004의 시간 경계와 설계의 저장·정리 방식을 구체화한다. (AC: AC-004)

## 2. 구현과 검증

- [ ] 2.1 예약자 확인과 조건부 상태 전이를 구현한다. (AC: AC-001, AC-002, AC-003)
- [ ] 2.2 요청 키별 결과와 취소 이력을 원자적으로 기록한다. (AC: AC-001, AC-004)
- [ ] 2.3 본인 성공, 타인 거부, 사용 중 충돌 각각의 반환값과 저장 상태를 확인한다. (AC: AC-001, AC-002, AC-003)
- [ ] 2.4 동일 키의 순차·동시 재시도와 저장 실패 후 재시도를 검증한다. (AC: AC-004)
