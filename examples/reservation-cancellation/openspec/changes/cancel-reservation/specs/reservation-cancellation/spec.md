## ADDED Requirements

### Requirement: 예약자의 취소 요청

서비스는 프로젝트 루트 `docs/domain/cancellation-policy.md`의 R-01~R-03에 따라 요청 결과를 반환해야 한다(SHALL).

#### Scenario: [AC-001] 예약자가 확정 예약을 취소한다
- **WHEN** 인증된 예약자가 본인의 확정 예약에 새 요청 키로 취소를 요청한다
- **THEN** 처리 결과와 상세 조회 상태가 취소됨이고 취소 이력이 한 건 생긴다

#### Scenario: [AC-002] 다른 회원이 취소를 요청한다
- **WHEN** 인증된 다른 회원이 해당 예약의 취소를 요청한다
- **THEN** 권한 거부를 반환하고 기존 상태·처리 결과를 공개하지 않으며 취소 이력을 추가하지 않는다

#### Scenario: [AC-003] 사용 중인 예약의 취소를 요청한다
- **WHEN** 예약자가 본인의 사용 중인 예약에 새 요청 키로 취소를 요청한다
- **THEN** 상태 충돌을 반환하고 조회 상태는 사용 중이며 취소 이력이 생기지 않는다

#### Scenario: [AC-004] 성공한 요청을 같은 키로 재시도한다
- **WHEN** 예약자가 성공한 취소와 같은 예약·요청 키로 즉시 다시 요청한다
- **THEN** 첫 요청과 같은 처리 결과를 반환하며 취소 이력은 한 건으로 유지된다
