# 작업실 문서 지도

- [제품 개요](product/brief.md)에서 문제와 첫 출시 범위를 확인한다.
- [용어](domain/glossary.md)와 [취소 정책](domain/cancellation-policy.md)이 업무 원본이다.
- [프로젝트 설정](project/profile.md)에서 기술 결정과 검토 방식을 확인한다.
- 변경 식별자는 `cancel-reservation`이다. `openspec/changes/cancel-reservation/`에서 제안, 명세 변경분, 설계, 작업, 검증 기록을 순서대로 읽는다. 첫 기능이라 아직 현재 명세가 없다. 완료 시 현재 명세는 `openspec/specs/`, 과거 변경 기록은 `openspec/changes/archive/`에 둔다.
